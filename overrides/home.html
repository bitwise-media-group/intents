// WHAT EVERY INTENT KEEPS

More capability, the same blast radius.

No credentials in pods

No model key, forge token or cloud credential ever reaches an agent pod. Codex moves onto the broker, copilot goes, and admission refuses any agent pod that mounts a Secret.

Broker-only egress

Agent pods reach the broker and the artifact server and nothing else: no TCP 443, no DNS. Model vendors' web tools are refused, and dependencies arrive through inspectable broker routes.

Git is the source of truth

Requests, plans, approvals and run records are immutable files in git. Custom resources carry the state, and GitHub issues are a one-way projection.

Approval binds bytes

An approval names the commit and sha256 of the plan it approves. The build receives exactly those bytes, re-hashed at launch, and nothing else of the request.

Spend bounded up front

Cost limits per pod, per hour and per run, a per-intent ceiling and bounded revision rounds, all measured by the broker rather than reported by the agent.

Humans gate both ends

A human approves every plan and merges every pull request. Branches are never force-moved, so human commits on a pull request survive every revision.
